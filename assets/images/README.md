# Original CV Images

Copy the three original company images into this directory with these exact filenames:

- dequest.png
- image.png
- rivalz_(1).png

The cv-image.html include will display them automatically in the existing CV positions.
Names are case-sensitive. Keep the actual PNG extension; renaming a JPEG extension to .png is not a format conversion.
The screenshot of the website is not the original image.png referenced by the Master CV.

Original Notion references:

- Daria%20Krivushkina/dequest.png
- Daria%20Krivushkina/image.png
- Daria%20Krivushkina/rivalz_(1).png

Riftvale displays the original animated GIF directly from Giphy. No local GIF or static frame is required:
https://media.giphy.com/media/FHWRYD5iLI68FzmuZd/giphy.gif

Contact icons are inline SVG in _includes/contact-icon.html. Original contact SVG image files are not needed.

Commit and push the image files together with the site update to publish them.
